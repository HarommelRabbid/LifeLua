camera

Using the front and back cameras. More...

Detailed Description

Start a camera with camera.start(), then get each new frame as an image with camera.output(). Only one camera can be running at a time. All the setting functions work the same way: call them with a value to change the setting, or without one to get the current value. They raise an error if the camera wasn't started.

camera.start(SCE_CAMERA_DEVICE_BACK, SCE_CAMERA_RESOLUTION_640_480)
camera.effect(SCE_CAMERA_EFFECT_SEPIA)
while true do
controls.update()
local frame = camera.output()
frame:display(160, 32)
local qr = frame:qrscan()
if qr then draw.text(10, 10, "QR code: "..qr, color.new(255, 255, 255)) end
if controls.pressed(SCE_CTRL_CIRCLE) then break end
draw.swapbuffers()
end
camera.stop()
