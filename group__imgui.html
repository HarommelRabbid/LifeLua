imgui

Windows, menus, buttons and other UI widgets (uses Dear ImGui) More...

Detailed Description

ImGui is an "immediate mode" UI library: there are no button objects to create or keep. Instead, every frame you call the widget functions in the order they should appear, and each one tells you right away if the user interacted with it (e.g. imgui.button() returns true on the frame it's pressed).

Call imgui.init() once at the start, then put your widgets between imgui.renderinit() and imgui.renderterm() in your main loop:

imgui.init()
imgui.darktheme()
imgui.touch(true) -- use the touch screen
imgui.gamepad(true) -- use the buttons/D-pad to move between widgets
local sound = true
local level = 1
local levels = {"Easy", "Normal", "Hard"}
while true do
imgui.renderinit()
imgui.nextwindowposition(20, 20, ImGuiCond_FirstUseEver)
imgui.nextwindowsize(400, 250, ImGuiCond_FirstUseEver)
imgui.windowbegin("Settings")
imgui.text("Hello from ImGui!")
sound = imgui.checkbox("Sound", sound)
level = imgui.combobox("Difficulty", level, levels)
if imgui.button("Start") then
-- start the game with levels[level]
end
imgui.windowend()
imgui.renderterm()
draw.swapbuffers()
end

You can draw other things (with draw, image, ...) in the same frame; draw them before imgui.renderterm() to have the ImGui windows on top of them.

Note
The text of imgui.text(), imgui.disabledtext(), imgui.wrappedtext() and imgui.tooltip() is read as a C format string, so write %% to show a % sign.
