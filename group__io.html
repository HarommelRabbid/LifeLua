io

Files, folders, archives & hashes (extends Lua's io library) More...

Detailed Description

These functions are added to Lua's standard io library, so io.open(), io.read(), etc. still work like in normal Lua (see the Lua manual).

Paths on the PS Vita start with a partition, for example:

  • app0: is your app's own folder, where main.lua is
  • ux0:data/ is the usual place to save your app's files
  • ux0:, ur0:, uma0:, imc0:, ... are the memory card and other storage
if not io.exists("ux0:data/myapp") then
io.newfolder("ux0:data/myapp")
end
local file = io.open("ux0:data/myapp/save.txt", "w")
file:write("Hello!")
file:close()

boolean io.archive ( string contents,
string archive_path,
string format )

Creates an archive from a folder, or from a list of files

Parameters
contentsEither a folder path (everything inside it is added), or a table where each key is a file path and each value is the name it gets inside the archive
archive_pathPath of the archive to create
formatArchive format (optional, default: "zip"). One of "zip", "7z", "gnutar", "ustar", "v7tar", "xar", "iso9660", "ar_bsd", "ar_svr4", "warc" or "raw"
Returns
true when done
Example:
io.archive("ux0:data/myapp", "ux0:data/myapp_backup.zip")
io.archive({["ux0:data/myapp/save.txt"] = "save.txt"}, "ux0:data/save.7z", "7z")

◆ io.extract()

nil io.extract ( string archive,
string destination )

Extracts an archive (.ZIP, .7Z, .RAR, .TAR, .VPK, ...). Missing folders are created.

If you define a global function called LifeLuaArchiveExtracting, it's called for each file before it's extracted. You can use it to draw a progress screen.

Parameters
archivePath to the archive
destinationFolder to extract into
Example:
function LifeLuaArchiveExtracting(name, index, size)
draw.text(10, 10, "Extracting file #"..index..": "..name, color.new(255, 255, 255))
draw.swapbuffers()
end
io.extract("ux0:data/game.zip", "ux0:data/game")

◆ io.list()

table io.list ( string path)

Lists the contents of a folder

Parameters
pathPath of the folder
Returns
nil if the folder can't be opened, otherwise a list with one table per file/folder, with these fields:
  • string name: File or folder name
  • string path: Full path
  • boolean isafolder: true for folders
  • number size: Size in bytes
  • string created, modified, accessed: Dates in the "YYYY-MM-DD HH:MM:SS" format
Example:
for i, item in ipairs(io.list("ux0:data")) do
print(item.name, item.isafolder and "folder" or item.size.." bytes")
end
