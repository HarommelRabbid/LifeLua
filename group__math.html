math

Extra math functions (extends Lua's math library) More...

Detailed Description

These are added to Lua's standard math library, so math.floor(), math.random(), etc. still work like in normal Lua (see the Lua manual).

Checks if a number is between a minimum and a maximum (both included)

Parameters
numThe number
minThe minimum
maxThe maximum
Returns
true if min <= num <= max
Example:
-- Is the touch inside a button?
if math.inrange(touch.x, 100, 300) and math.inrange(touch.y, 50, 100) then ... end

number math.range ( number num,

Keeps a number between a minimum and a maximum (also known as "clamp")

Parameters
numThe number
minThe minimum
maxThe maximum
Returns
min if num is smaller than it, max if num is bigger than it, otherwise num
Example:
volume = math.range(volume + 10, 0, 100) -- never goes over 100
