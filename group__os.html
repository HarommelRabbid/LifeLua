os

System dialogs, apps, battery, power & system information (extends Lua's os library) More...

Detailed Description

These functions are added to Lua's standard os library, so os.time(), os.date(), os.clock(), etc. still work like in normal Lua (see the Lua manual).

System dialogs

The dialog functions (os.keyboard(), os.message(), os.importphoto(), ...) show one of the PS Vita's own dialogs and wait until it's closed, then return the result. While a dialog is open your main loop doesn't run, so the screen behind it is empty. To draw something behind a dialog (or to update it, like a progress bar), define the dialog's callback function. It's called once per frame while that dialog is open:

Dialog function Callback function
os.keyboard() LifeLuaIMEDialog()
os.message() LifeLuaMessageDialog()
os.systemmessage() LifeLuaSystemMessageDialog()
os.errormessage() LifeLuaErrorCodeDialog()
os.progressmessage() LifeLuaProgressMessageDialog()
os.importphoto() LifeLuaPhotoImportDialog()
os.importvideo() LifeLuaVideoImportDialog()
os.photoreview() LifeLuaPhotoReviewDialog()
os.cameraimport() LifeLuaCameraImportDialog()

Don't call draw.swapbuffers() inside these callbacks, LifeLua does it for you.

function LifeLuaIMEDialog()
background:display(0, 0) -- keep the app's background visible behind the keyboard
end
local name = os.keyboard("What's your name?", "Harommel")
if name then
os.message("Hello, "..name.."!")
end
