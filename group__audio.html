audio

Playing music and sounds. More...

Detailed Description

Supported formats: .MP3, .WAV, .OGG, .FLAC, .OPUS and tracker modules (.MOD, .XM, .IT, .S3M, ...). The format is picked from the file extension. Any other file is played as raw 16-bit stereo PCM at 48000 Hz.

Every function that takes an audio as its first parameter can also be called as a method:

local music = audio.load("app0:music.ogg")
music:play(true) -- loop forever
while true do
draw.text(10, 10, string.format("%.1f / %.1f s", music:elapsed(), music:duration()), color.new(255, 255, 255))
draw.swapbuffers()
end
Note
Only one audio can play at a time: playing another one replaces the current one.
