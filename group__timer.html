timer

Measuring time (stopwatches) More...

Detailed Description

Every function that takes a timer as its first parameter can also be called as a method, e.g. t:start() and t:elapsed().

local t = timer.new()
t:start()
while true do
controls.update()
if controls.pressed(SCE_CTRL_CROSS) then t:pause() end -- pause/resume
draw.text(10, 10, string.format("%.2f seconds", t:elapsed()), color.new(255, 255, 255))
draw.swapbuffers()
end
