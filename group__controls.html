controls

Buttons, analog sticks, touch screens & motion sensors. More...

Detailed Description

Call controls.update() once at the start of every frame, then check the buttons and sensors. The difference between the button functions:

  • controls.pressed(): true only on the frame the button goes down (good for menus)
  • controls.held(): true on every frame while the button stays down, except the first one
  • controls.released(): true only on the frame the button is let go
  • controls.check(): true on every frame while the button is down
local x = 480
while true do
controls.update()
if controls.check(SCE_CTRL_LEFT) then x = x - 4 end
if controls.check(SCE_CTRL_RIGHT) then x = x + 4 end
if controls.pressed(SCE_CTRL_START) then break end -- exit the loop
draw.circle(x, 272, 20, color.new(255, 255, 255))
draw.swapbuffers()
end

◆ controls.fronttouch()

table controls.fronttouch ( )

Gets the fingers touching the front touch screen

Returns
A list with one table per finger (empty if nothing is touching). Each table has these fields:
  • x, y: Position in screen pixels
  • force: How hard the finger is pressing
  • id: A number that stays the same for a finger while it keeps touching
Example:
local touch = controls.fronttouch()
for i = 1, #touch do
draw.circle(touch[i].x, touch[i].y, 30, color.new(255, 255, 255))
end

◆ controls.update()

Reads the latest state of the buttons, sticks, touch screens and motion sensors. Call this once per frame, before using any other function of this library.

Parameters
