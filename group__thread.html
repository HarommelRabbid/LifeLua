thread

Running a function at the same time as the rest of your app. More...

Detailed Description

Every function that takes a thread as its first parameter can also be called as a method, e.g. t:start() and t:wait().

local done = false
local t = thread.new(function()
io.extract("ux0:data/big.zip", "ux0:data/big") -- slow work
done = true
end)
t:start()
while not done do
draw.text(10, 10, "Extracting...", color.new(255, 255, 255))
draw.swapbuffers()
end
Warning
Threads are experimental: they share the same Lua state as the main code, so running heavy code in a thread, or using the same variables/objects from several threads at once, may crash the app. Keep thread functions simple.
