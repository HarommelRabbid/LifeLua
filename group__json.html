json

Reading and writing JSON (uses cJSON) More...

Detailed Description

JSON objects become Lua tables with string keys, JSON arrays become Lua lists (starting at index 1), and the other way around.

local data = json.decode('{"name": "LifeLua", "tags": ["lua", "vita"], "stars": 5}')
print(data.name, data.tags[1], data.stars) -- LifeLua lua 5
data.stars = data.stars + 1
local text = json.encode(data)

JSON's null can't be stored as Lua's nil (a table can't hold nil), so it's represented by a special value instead. Use json.isnull() to check for it, and json.null to write it.

◆ json.encode()

string json.encode ( table value,
boolean minified )

Converts a Lua value to a JSON string. A table whose keys are all numbers becomes a JSON array, any other table becomes a JSON object (keys that aren't strings are skipped). Functions and other unsupported values become null.

json.stringify() is the same function under another name.

Parameters
valueThe table (or other value) to convert
minifiedtrue to leave out the spaces and line breaks (optional, default: false, the JSON is nicely formatted)
