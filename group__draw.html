draw

Drawing shapes and text on the screen (uses vita2d) More...

Detailed Description

Everything drawn with this library (and with images, ImGui, etc.) is drawn to a hidden buffer first. Nothing appears on the screen until you call draw.swapbuffers(), which shows the finished frame and clears the buffer for the next one. Because of this, a LifeLua app is usually one big loop:

local white = color.new(255, 255, 255)
while true do
draw.text(10, 10, "Hello World!", white)
draw.rect(10, 40, 100, 50, color.new(255, 0, 0))
draw.swapbuffers()
end

The screen is 960 × 544 pixels. (0, 0) is the top-left corner, x grows to the right and y grows downwards.

Every parameter written as color accepts either a color value made with color.new() or a plain number in 0xAABBGGRR order (see tocolor()).

◆ draw.cliprect()

number y1,

number y2 )

Sets a rectangular clipping area, useful for cutting off long text or making scrollable areas. Only has an effect while clipping is turned on with draw.enableclip().

Parameters
x1Left edge of the area
y1Top edge of the area
x2Right edge of the area (this is a position, not a width)
y2Bottom edge of the area (this is a position, not a height)
Example:

draw.text(10, 10, "This long text gets cut off at x = 110", white)
draw.enableclip(false)

◆ draw.text()

nil draw.text ( number x,
number y,
string text,
color color,
number size,
font font )

Draws text on the screen

After the 4 required parameters, you can choose the font and the size in any of these ways:

  • draw.text(x, y, text, color): system font (PGF), size 1
  • draw.text(x, y, text, color, size): system font (PGF) at size
  • draw.text(x, y, text, color, font) or draw.text(x, y, text, color, font, size): a font loaded with font.load()
  • draw.text(x, y, text, color, size, font): same as above, with the size first
  • draw.text(x, y, text, color, true) / draw.text(x, y, text, color, true, size): system PVF font (false = system PGF font)
  • draw.text(x, y, text, color, size, true): same as above, with the size first
Parameters
xLeft position of the text
yTop position of the text
textThe text to draw
colorColor of the text
sizeText scale, 1 is the normal size (optional, default: 1)
fontA font from font.load(), or a boolean to pick the system PVF (true) or PGF (false) font (optional)
Example:
local white = color.new(255, 255, 255)
local myfont = font.load("app0:font.ttf")
draw.text(10, 10, "System font", white)
draw.text(10, 40, "Twice as big", white, 2)
draw.text(10, 100, "Custom font", white, myfont)

Gets how wide a text will be when drawn with draw.text()

Accepts the same size/font combinations as draw.text(), e.g. draw.textwidth(text), draw.textwidth(text, size), draw.textwidth(text, font), draw.textwidth(text, font, size), draw.textwidth(text, true), etc.

Parameters

Returns
The width in pixels
Example:
