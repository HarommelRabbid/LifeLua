Extra table functions (extends Lua's table library) More...

Detailed Description

These are added to Lua's standard table library and work on lists (tables with keys 1, 2, 3, ...). Note that the value comes first and the list second.

Checks if a value is in a list

Parameters

listThe list to search
Returns
true if the value is in the list
Example:

Removes the first time a value appears in a list (the items after it move down by one)

Parameters
valueThe value to remove
listThe list to remove it from
Returns
The removed value, or nothing if it wasn't found
Example:
local items = {"a", "b", "a"}
table.removefirst("a", items) -- items = {"b", "a"}
