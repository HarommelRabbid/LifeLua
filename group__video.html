video

Playing videos (uses the system's AvPlayer) More...

Detailed Description

Plays .MP4 videos (H.264 video with AAC audio). Only one video can be loaded at a time, so these functions don't take a video object; they all control the currently loaded video. All the functions except video.load() raise an error if no video is loaded.

video.load("ux0:data/myapp/intro.mp4", true) -- load and start playing
while video.active() do
controls.update()
video.output() -- draw the current frame
if controls.pressed(SCE_CTRL_CROSS) then video.stop() end
draw.swapbuffers()
end
video.close()
