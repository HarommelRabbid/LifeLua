◆ network.download()

nil network.download ( string url,
string path,
string useragent )

Downloads a file (HTTP or HTTPS). The app waits until the download is finished.

If you define a global function called LifeLuaNetworkDownload, it's called every time a piece of the file is downloaded, so you can show the progress. It receives these 5 numbers (the names you give them don't matter):

  1. Total bytes downloaded so far
  2. Total bytes written to the file so far
  3. Size of the whole file in bytes (0 if the server doesn't say)
  4. Bytes downloaded in this piece
  5. Bytes written in this piece
    Parameters
    urlThe URL of the file
    pathWhere to save the file
    useragentThe User-Agent sent to the server (optional, default: a desktop Chrome User-Agent)
    Returns
    nil if the connection or request failed
    Example:
    local white, blue = color.new(255, 255, 255), color.new(0, 0, 255)
    function LifeLuaNetworkDownload(downloaded, written, size)
    if size > 0 then
    draw.text(10, 10, math.floor(written * 100 / size).."% done", white)
    draw.rect(0, 505, written * 960 / size, 39, blue)
    end
    draw.swapbuffers()
    end
    network.download("https://example.com/file.zip", "ux0:data/file.zip")

◆ network.ftp.start()

table network.ftp.start ( boolean enable)

Starts or stops an FTP server on the PS Vita, so you can access its files from a computer.

Parameters
enabletrue to start, false to stop
Returns
When starting: a table with the fields ip (string) and port (number) to connect to. Raises an error if the server is already in the requested state.
Example:
local ftp = network.ftp.start(true)
network.ftp.adddevice("ux0:")
while true do
draw.text(10, 10, "Connect to "..ftp.ip..":"..ftp.port, color.new(255, 255, 255))
draw.swapbuffers()
end
