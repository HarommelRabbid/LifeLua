Extra string functions (extends Lua's string library) More...

Detailed Description

These are added to Lua's standard string library, so like the other string functions, they can be called as methods on any string:

local file = "Picture.PNG"
print(file:endswith(".png")) -- false
print(file:endswith(".png", true)) -- true (ignoring upper/lower case)

◆ string.split()

table string.split ( string str,
string delimiters )

Splits a string into a list of parts. Every character of delimiters counts as a separator, and empty parts are skipped.

Method form: str:split(delimiters)

Parameters
strThe string to split
delimitersThe separator character(s) (optional, default: " ")
Returns
A list of the parts
Example:
local parts = ("ux0:data/myapp/save.txt"):split("/")
-- parts = {"ux0:data", "myapp", "save.txt"}
local words = ("one, two,three"):split(", ")
-- words = {"one", "two", "three"}
